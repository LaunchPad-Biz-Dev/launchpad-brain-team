# _inbox — the one place the team writes

Optional. Your scheduled daily dump already feeds the Brain through Drive. If you work in Cowork with this
folder, you can also drop a markdown note into **your own folder** here (a client preference, a correction,
a decision, a fact the Brain was missing) and Commit + Push in GitHub Desktop.

Files disappear from here after the Mac Mini harvests them (twice daily). That means it worked: they are
now in the real Brain under `Raw/Team Inbox/{you}/`, and Apollo files them into the right note by the
next morning. Do not put passwords, API keys, or client financials here.
