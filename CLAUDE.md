## The "Chat Clip That" Command
When Anthony or any team member says **"chat clip that"** it means:
1. Take what was just discussed in this conversation
2. Identify which folder it belongs in (see folder guide below)
3. Save it as a note or update the relevant existing note in this vault
4. Confirm what was saved and where

This is the primary way the brain gets updated during conversations. Always execute this immediately when the phrase is used.

## Rules for Navigating This Vault
1. Always read this file first before answering questions about Launchpad
2. When "chat clip that" is said — save immediately, confirm where it was saved
3. When updating a note — add to it, never delete existing context unless told to
4. When unsure which folder something belongs in — use Intelligence as the default
5. When a new client, project, or team member is mentioned — create a note for them in the right folder
6. Keep notes concise but complete — future AI agents need to understand them without extra explanation
7. Date-stamp any new entries in Daily and Intelligence folders
8. If you find related notes — link them together using [[note name]] syntax
