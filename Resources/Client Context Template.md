# Client Context Template

> **Purpose:** This is the standardized template for every Launchpad client. AI agents pull from this note to create on-brand content, design assets, write copy, and plan campaigns. Every field marked with ⚠️ is required for agents to function properly. Fields marked with ➕ are recommended but not blocking.
>
> **How to use:** Duplicate this template into the Projects folder when onboarding a new client. Name the file with the client/brand name. Fill in every ⚠️ field during onboarding (Phases 1-3). Update as the relationship evolves.

## 9. CRM & Systems (GoHighLevel)

| Field | Value |
|-------|-------|
| ⚠️ GHL Sub-Account | Yes / No |
| ⚠️ GHL Location ID | (e.g., hbcsvkyO40fTLTbsL1lI — required for all CRM/social posting operations. Found in GHL: Settings > Business Profile, in the URL bar) |
| ⚠️ GHL Sub-Account API Token | (Private Integration Token created IN the sub-account — required for social media posting. Format: `pit-xxxxx`. Stored in `.env` as `GHL_TOKEN_{CLIENT}`) |
| ➕ GHL Sub-Account Name | |
| ➕ A2P Registration | Completed / Pending / Not Required |
| ➕ Active Automations | |
| ➕ Lead Follow-Up Sequences | Fast Five / Long-term Nurture / Custom |

> **CRITICAL:** The GHL Location ID is what agents use to target the correct sub-account for contacts, social posting, conversations, and pipeline operations. Without it, agents cannot interact with GHL for this client. Never use one client's Location ID for another client's operations.
>
> **IMPORTANT — Sub-Account API Token:** The agency-level GHL token does NOT have social media posting permissions. Each client sub-account needs its own Private Integration Token created from within the sub-account (Settings > Integrations > Private Integrations). Enable the "Social Planner" scope. Save the token in `.env` as `GHL_TOKEN_{CLIENTNAME}` and reference it here.

## Onboarding Checklist

Use this to track completion during onboarding. All ⚠️ items must be filled before the client is marked Active.

- [ ] Client Overview complete
- [ ] Brand Identity documented (voice, tone, archetype, pillars)
- [ ] Visual Identity captured (colors, typography, photo direction)
- [ ] At least one mood board linked
- [ ] Content strategy defined (pillars, deliverables, cadence)
- [ ] All active platforms listed with handles
- [ ] Ad strategy documented (if applicable)
- [ ] GHL sub-account set up (if applicable)
- [ ] GHL Private Integration Token created in sub-account with Social Planner scope (saved to `.env` as `GHL_TOKEN_{CLIENT}`)
- [ ] Google Drive created and linked
- [ ] Notion portal created and linked
- [ ] Team roster assigned
- [ ] First shot list / production brief linked
