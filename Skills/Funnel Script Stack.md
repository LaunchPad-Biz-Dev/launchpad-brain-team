# Funnel Script Stack

**Author of the format:** Kyle Fuller. Built for the LaunchPad CRM 15-video batch, 2026-07-29.

## Purpose

A layout for writing a **batch of short-form video scripts as one funnel** — top, middle, and bottom — where the funnel stage decides the campaign type and the call to action, and every script is written as word-for-word spoken beats the crew can shoot straight off the page.

This is an **option, not a replacement.** Our default pre-production output is still the plain-language Shoot Plan in `shoot-brief-builder` ([[Brief Creation]], [[Shot List Creation]]). Use this format when the ask is a paid-media script batch rather than a monthly content shoot.

---

## When to reach for this vs. what we already have

| Use this | Use the default Shoot Plan | Use [[UGC Script Creation]] |
|---|---|---|
| A batch of ads mapped to a paid funnel | A client's monthly content shoot | A single creator-delivered UGC piece |
| The CTA is set by a campaign objective | The CTA is set by the content idea | The CTA is set by the offer |
| Talent reads written lines | The crew shoots to a plain shot list | The creator improvises to a loose outline |
| You need copy locked before the shoot | You need the client to prep for a shoot day | You need a creator brief |

The two can be stacked: write the scripts in this format, then wrap them in a Shoot Plan for the client so they still get the plain-language version with logistics and a prep checklist.

---

## Who reads it

**Both client and crew.** Keep it that way:
- The **client** reads it to approve the message before we shoot. So no jargon in the script body — no "VO," "b-roll," "lower third."
- The **crew** shoots off the same page. Camera and coverage notes live in a separate block per video, never inside the spoken lines.

---

## The five elements

**HOOK** — the first line. Stops the scroll. Either spoken, or on-screen text (mark it: `On-screen text: "..."`). The video title should read as the hook, so a scroll through the doc reads like a list of hooks.

**VALUE** — the substance. Written as **one quoted line per beat.** One quote = one thing said = roughly one cut. Fragments are correct here. Do not write paragraphs.

**REHOOK** — optional. A short question or turn that re-grabs attention in the middle, before the second value block. Use it when a script needs a second act. Skip it when the script is short and direct — bottom-of-funnel usually does not need one.

**VALUE (second block)** — only if there is a REHOOK. Answers what the rehook asked.

**CTA** — one line, and it must match the campaign objective for that funnel tier. Never write a CTA the campaign type cannot deliver.

---

## Funnel tier locks the CTA

| Tier | Campaign type | CTA language |
|---|---|---|
| Top of funnel | Traffic | "Learn more about..." |
| Middle of funnel | Message | "Send us a message to..." |
| Bottom of funnel | Lead form | "Start your free trial" / "Get started" |

Change the tier and the CTA changes with it. This is the part people get wrong — a "send us a message" CTA on a traffic campaign wastes the spend.

---

## The template

```
{OFFER OR CLIENT} — {N}-Video Funnel Scripts

TOP OF FUNNEL — Traffic Campaign (CTA: Learn More)

{Video title — reads as the hook}
HOOK    "{one line that stops the scroll}"
VALUE   "{beat}" "{beat}" "{beat}" "{beat}" "{beat}"
REHOOK  "{short question or turn}"          ← optional
VALUE   "{beat}" "{beat}" "{beat}"          ← only if there's a rehook
CTA     "{matches the campaign objective}"

{next video...}

MIDDLE OF FUNNEL — Message Campaign (CTA: Send Message)
{same block structure}

BOTTOM OF FUNNEL — Lead Form Campaign (CTA: Start Free Trial / Get Started)
{same block structure}
```

**Crew block** — kept separate from the script, one per video, so the client's read stays clean:

```
Coverage:  {talking head / POV / screen record / b-roll over VO}
Talent:    {who's on camera}
Setting:   {where}
Props:     {what we need}
Length:    {target runtime}
```

---

## Rules

1. **One quote, one beat.** If a value line has two ideas in it, split it into two lines.
2. **Short beats.** Most of Kyle's land at 5–12 words. Fragments beat full sentences.
3. **Title = hook.** If the title isn't the hook, rewrite one of them.
4. **Rehook only when earned.** Roughly: use it top and middle of funnel, drop it at the bottom where the viewer is already warm and wants the direct answer.
5. **CTA matches the campaign.** Non-negotiable — see the table above.
6. **Count the beats before you shoot.** Five value beats means five setups or five cuts. That's the shot list falling out of the script for free.
7. **Specifics over adjectives.** "You've searched an email thread for a client's number more than once this week" beats "you're disorganized."
8. **Symptoms first, product second.** The strong scripts open on something the viewer recognizes about their own week, then name what's causing it.
9. **No jargon in the spoken lines.** Camera language lives in the crew block only.
10. **Plain human voice.** See `feedback_captions_human_not_ai` — kill the dash tic, write how a person actually talks.

## Worked example — one per tier

Verbatim from Kyle's LaunchPad CRM batch, 2026-07-29.

**Top of funnel — Traffic (CTA: Learn More)**

```
5 Signs Your Business Is Still Running on Sticky Notes
HOOK   "5 signs your business is still being run on sticky notes."
VALUE  "One, your customer info is scattered across three different apps."
       "Two, you've searched an email thread for a client's number more than once this week."
       "Three, a lead texted you back and you genuinely forgot who they were."
       "Four, someone on your team followed up with a customer twice because nobody else knew it already happened."
       "Five, your 'system' is a notebook, a spreadsheet, and a prayer."
CTA    "Learn more about how to fix it."
```

**Middle of funnel — Message, with a rehook (CTA: Send Message)**

```
The Real Reason Your Team Keeps Dropping Leads
HOOK    "The real reason your team keeps dropping leads has nothing to do with effort."
VALUE   "Your team isn't lazy."
        "They're just working blind."
        "No one can see where a lead actually stands."
        "So follow-ups get missed, not because people don't care, but because nobody had visibility."
REHOOK  "So what fixes that?"
VALUE   "One system everyone can see."
        "Every lead, every stage, every next step, visible to the whole team."
        "No more guessing who followed up with who."
CTA     "Send us a message to see how it works."
```

**Bottom of funnel — Lead Form, no rehook (CTA: Get Started)**

```
Here's Exactly What You Get for $197 a Month
HOOK   "Here's exactly what you get for $197 a month."
VALUE  "15 days free before you pay anything."
       "$10 in complimentary SMS and email credit."
       "Full onboarding support."
       "Technical support whenever you need it."
       "Room to customize as your business grows."
CTA    "Get started today."
```

Note the shape across the three: the hook gets more concrete as you go down funnel, the rehook disappears, and the value beats shift from symptoms the viewer recognizes to what they actually receive.

## Variants seen in the source batch

- **POV / on-screen hook** — the hook is text on screen instead of a spoken line, and the value beats become observed moments rather than statements. Mark it `On-screen text: "POV: you're a real estate agent with 12 active leads and zero system."`
- **Vertical cut** — same script re-pointed at one industry. Kyle ran the real-estate version of both the POV script and the middle-of-funnel pipeline script. Good pattern for reusing a proven structure across verticals without rewriting from scratch.
- **Feature list** — the value block is a numbered list ("One... Two... Three..."). Works at both top and bottom of funnel; the top-of-funnel version lists symptoms, the bottom-of-funnel version lists what's included.
