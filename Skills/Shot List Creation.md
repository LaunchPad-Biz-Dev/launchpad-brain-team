# Shot List Creation

> **Shipping a callsheet?** This note is the shot-type *vocabulary* — talking heads, B-roll, POV,
> skits, drone, and what belongs in each. For producing the actual field document, use
> [[Callsheet Generation]] with the templates in [[Callsheet System]]. That path produces an
> interactive, offline HTML callsheet the shooter checks off on the floor and the client can read
> as a deliverable.

## Purpose
A shot list is the operational blueprint for a production day. It breaks down exactly what needs to be captured on set: talking heads, B-roll, photos, POV footage, skits, etc. A good shot list prevents missed shots, saves time in post, and ensures deliverables are complete.

**Golden Rule:** Every shot should tie back to an end-use deliverable (a YouTube video, a Reel, a photo carousel, etc.).

---

## Shot List Structure (Standard Template)

Use this structure for all production days:

### Header Info
- **Client/Project Name**
- **Shoot Date**
- **Location(s)**
- **Gear Used** (camera, gimbal, drone, etc.)
- **Talent/Key People**
- **Deliverables Expected** (final videos, photo count, etc.)

### Main Categories

#### 1. **Talking Heads** *(Direct-to-Camera Footage)*
**Purpose:** Educational, testimonial, pitch, or CTA-focused content

**Typical shots:**
- Direct-to-camera (tripod)
- Direct-to-camera (gimbal - walk and talk)
- Multiple takes/angles
- Various expressions or deliveries (serious, casual, friendly, urgent)

**Template:**
```
🎤 TALKING HEADS

- [ ] Hero Q&A (Direct-to-Camera)
  - Shot description (location, framing, style)
  - Alt takes needed? (yes/no)

- [ ] FAQ Series
  - Topic 1: [description]
  - Topic 2: [description]
  - etc.

- [ ] CTAs (Multiple tones)
  - CTA 1 (professional)
  - CTA 2 (urgent)
  - CTA 3 (educational/trust)
  - etc.
```

---

#### 2. **Still Photography** *(A7RV, Canon, Mirrorless)*
**Purpose:** Photo galleries, social carousels, website assets, print

**Typical shots:**
- Hero/brand imagery
- Action shots
- Detail/close-ups
- Portraits (individual + group)
- Lifestyle / environmental
- Behind-the-scenes
- Props and flat lays

**Template:**
```
📸 PHOTO LIST

☐ Hero shot (describe: framing, location, intent)
☐ Brand assets (logo/location context)
☐ Team/talent portraits
☐ Action/process shots
☐ Close-ups (product, detail)
☐ Environmental/lifestyle
☐ Flat lay / props
☐ BTS of filming
```

**Best Practices:**
- Shoot at least 3 angles of key shots
- Capture both wide and tight framings
- Bracket exposure if lighting is tricky
- Get shots both vertical and horizontal (for multi-platform use)

---

#### 3. **B-Roll + POV Footage** *(FX30, Insta360, Gimbal)*
**Purpose:** Scene-setting, transitions, transitions, visual storytelling, platform-specific formats

**Typical shots:**
- POV walking / approach shots
- Gimbal walking shots
- Environmental close-ups
- Hand/detail actions
- Aerial (drone)
- Over-the-shoulder
- Process/workflow shots
- Reaction B-roll

**Template:**
```
🎥 POV + B-ROLL

- [x] POV: Approaching location
- [x] POV: Grabbing/handling something
- [ ] Gimbal: Walking shot
- [ ] Close-up: Hands doing task
- [ ] Over-shoulder: Person speaking
- [ ] Aerial: Wide establishing shot
- [ ] Detail: Process/equipment close-up
- [ ] Environmental: Location ambiance
```

---

#### 4. **Skits + Comedy Content** *(Vertical, Short-Form)*
**Purpose:** Entertainment, trend-following, personality-driven content

**Typical shots:**
- Setup / establishing
- Punchline / revelation
- Reactions
- Multiple takes/angles
- Alt versions (different deliveries, different talent)

**Template:**
```
📱 SKIT SHOTS

☐ Skit 1: [Skit name]
  - Scene 1: [description and shot type]
  - Scene 2: [description and shot type]
  - Alt takes: [yes/no, how many]

☐ Skit 2: [Skit name]
  - etc.
```

---

#### 5. **Drone Shots** *(DJI or equivalent)*
**Purpose:** Aerial establishing, scale, location showcasing

**Typical shots:**
- Aerial approach
- Top-down establishing
- Flyover
- Reveal shot (reveals location/scene)

**Template:**
```
🚁 DRONE SHOTS

☐ Aerial approach (describe path)
☐ Top-down establishing
☐ Flyover (starting point → ending point)
☐ Reveal shot (what's being revealed)
```

## Shot List Best Practices

1. **Be Specific:** "Gimbal walking shot of tech approaching" > "B-roll"
2. **Estimate Time:** Add rough duration needed for each section (e.g., "10 talking head seconds needed")
3. **Checkbox Progress:** Check off shots as they're captured to track real-time progress
4. **Capture Variations:** Always get 2-3 versions of critical shots
5. **Get Extra:** Capture 20-30% more than you think you need
6. **Note Technical Details:** (lighting setup, location sound, special considerations)
7. **Link to Deliverables:** Each shot section should map to a final video or asset type

## Shot List Organization & Execution

### Equipment Categories in Shot Lists

**🎤 Talking Heads**
- Recorded on FX30 (primary) or A7RV
- Tripod-mounted (static) or gimbal (walk-and-talk)
- Multiple takes of each topic/CTA
- Lavalier + shotgun mic for clean audio
- Typically 2–4 takes per talking head for editor choice

**📸 Photo List (A7RV)**
- Specific categories: hero shots, team portraits, action/process, detail/close-ups, lifestyle, environmental, flat lay, BTS
- Multiple angles of key shots (3 minimum)
- Both vertical and horizontal framings (for multi-platform use)
- Bracket exposure if lighting is difficult
- Get extras beyond minimum needs (20–30% overage)

**🎥 POV + B-Roll (FX30 + Gimbal + Insta360)**
- POV footage: First-person perspective of actions or approach
- Gimbal shots: Smooth walking shots, reveals, tracking
- Close-ups: Hands doing work, detail actions, textures
- Over-shoulder: Person speaking or working
- Environmental: Location ambiance, wide establishing
- Aerial: Drone footage (top-down, flyovers, reveals)
- Process shots: Start-to-finish of a task or service

**📱 Skit/Comedy Shots (iPhone – Vertical)**
- Shot vertically (9:16 aspect ratio)
- Multiple takes per scene (for editing variations)
- Wide establishing, medium reaction shots, close-ups on punchline
- Alt deliveries (serious vs. comedic, different talent)
- Cutaway shots for B-roll punch

**🚁 Drone Shots (DJI)**
- Aerial establishing (approaching location)
- Top-down (revealing location/property)
- Flyover (moving reveal shots)
- Tracking shots (following subject or path)
- Pull-back/reveal moments

## Workflow

**Before Shoot:**
- Share shot list with team 24 hours prior (full crew review)
- Confirm location, talent, timing, and access
- Review gear checklist + backup equipment
- Brief team on visual style + tone
- Scout location if new (lighting conditions, sound, permissions)
- Print or digitize shot list for real-time checking

**During Shoot:**
- Assign shot list owner (someone checking items off in real-time)
- Print or use digital checklist on tablet (check off as you capture)
- Photograph the final completed list (proof of execution)
- Note any issues, pivots, or missing shots immediately
- Capture extra footage (30% overage beyond minimum needs)
- Organize footage by category as you shoot (different cards/folders per shot type)
- Take photos of camera settings/ISO/aperture for editor notes

**After Shoot:**
- Archive original shot list with footage (same folder)
- Create shot log: note which takes are keepers, which to avoid
- Organize all footage clearly (by shot type, camera, date)
- Write notes on any technical issues (bad audio, lighting problems, weather)
- Provide editor with shot list + organized footage + shot notes
- Document any unused shots or pivots from original plan

---

## Best Practices Summary

1. **Specificity:** "Gimbal walking shot of tech approaching house" > "B-roll"
2. **Time Estimates:** Note how long each section should take (talking heads: 10 min, B-roll: 20 min, etc.)
3. **Checkbox Progress:** Check off shots in real-time to track completion and manage shoot time
4. **Variations:** Always capture 2–3 versions of critical shots (different takes, angles, or talent)
5. **Overage:** Shoot 20–30% more than needed; editors appreciate having options
6. **Technical Notes:** Document lighting setup, location sound issues, special considerations
7. **Linkage:** Each shot section should map to a final video or deliverable
8. **Organization:** Name files and folders clearly so editors don't hunt for footage
9. **Redundancy:** Have backup cards/storage; don't rely on single device
10. **Communication:** If shooting schedule changes mid-day, update team immediately
