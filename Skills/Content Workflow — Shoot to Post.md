# Skill: Content Workflow — Shoot to Post

This is the core production workflow that needs to be tightened and automated. The process moves content from ideation through posting, with multiple handoffs that must stay coordinated.

---

## The Full Pipeline

### Phase 1: Pre-Production — Planning & Preparation

**Owner:** [[Abril Rodriguez]] (Creative Director)

**Steps:**
1. Review client's quarterly plan and monthly execution plan
2. Create detailed shot list based on monthly themes
3. Prepare production brief (locations, client needs, specific angles, timing, props)
4. Send pre-production form to client for input
5. Confirm shoot schedule with [[Robert Quiantanace]] (Launchpad Productions)
6. Coordinate with [[Kyle Fuller]] on social media content angles
7. Confirm any talent, props, or special equipment needs
8. Create Notion task for shoot with all stakeholders linked

**Output:** Shot list, production brief, confirmed shoot date, client pre-production form completed

---

### Phase 2: Production — Shoot Day

**Owner:** [[Robert Quiantanace]] & [[Kyle Fuller]]

**Steps:**
1. Execute shoot according to shot list
2. Capture raw footage and photos
3. Take test shots and review quality
4. Upload raw assets to Google Drive **immediately after shoot** (same day)
5. Create folder structure: [Client Name] / [Shoot Date] / [Raw Files]
6. Tag Abril that assets are uploaded

**Output:** Raw assets in Google Drive, organized and ready for assignment

---

### Phase 3: Post-Production Assignment ← CURRENT BOTTLENECK

**Owner:** [[Abril Rodriguez]] (Creative Director)

**Steps:**
1. Review raw assets in Google Drive
2. Create detailed edit specs (length, style, music, captions, calls-to-action, etc.)
3. Assign to correct editor based on content type:
   - **Videos** → [[Munzelle Jazz]] (team manager) or [[Ral Luna]] (Philippines)
   - **Short clips** → [[Opus.ai]] for initial cut, then pass to editor for refinement
   - **Graphics/Design** → [[Arija Imendia]] or [[David Canizalez]] (El Salvador)
   - **Podcasts** → Specific podcast post-production workflow
4. Create Notion task with assignment and deadlines
5. Link editor, client, and Abril in task

**Known bottleneck:** Manual assignment and slow notification. Needs [[Emigen Lagman]] automation or GHL workflow.

**Output:** Clear assignment, editor knows what to create, deadline set

---

### Phase 4: Editing & Revisions

**Owner:** Video/Graphics editors (Philippines/El Salvador remote teams)

**Steps:**
1. Editor receives assignment and spec details
2. Editor completes first cut (typically 3-5 business days)
3. Editor uploads draft to shared Google Drive folder (per client)
4. Notifies Abril that draft is ready for review
5. [[Abril Rodriguez]] reviews draft and provides feedback:
   - Approval to send to client
   - Revision requests (communicate directly to editor)
6. **Client revision requests → Direct to editor** (NOT through Abril)
   - **Current gap:** Revision requests sometimes don't reach editor directly; slows turnaround
7. Editor makes revisions (typically 1-2 business days per revision round)
8. Final version sent to Abril for final approval

**Editing tools:**
- **Video:** CapCut (primary), Premiere Pro (learning)
- **Graphics/Design:** Canva, Adobe Creative Suite
- **Clip cutting:** Opus.ai (cuts raw footage into social-ready shorts, then editor refines)

**Output:** Final edited asset, ready for delivery

**Output:** Assets ready for scheduling, promotion, or client handoff

## Known Gaps to Fix (Priority Order)

1. **Raw content upload delay** — Assets not reaching Google Drive same-day after shoot
   - *Solution:* Set expectation that Robert/Kyle upload before leaving location
   - *Automation:* [[Emigen Lagman]] could create reminder/checklist

2. **Client revision requests don't flow to editors** — Breaks direct communication
   - *Solution:* Establish clear protocol: Client emails Abril, Abril forwards immediately to editor (CC'd)
   - *Automation:* [[Emigen Lagman]] create Notion template for revision requests

3. **Completion status not communicated** — Cynthia/Amber don't know when assets are ready
   - *Solution:* Abril sends Slack message and updates Notion the moment assets are finalized
   - *Automation:* Notion automation that notifies Slack channel when status = "Delivered"

4. **No automated handoff between phases** — Each phase requires manual check-in
   - *Solution:* Notion task dependencies + Slack notifications
   - *Automation:* GHL workflow that tracks progress and alerts stakeholders

## Content Creation Philosophy (from LP University)

Every piece of content should follow this framework:

**Phase 1: Pre-Production (Research)**
- Study what's working on the client's platforms
- Look for patterns: hooks, transitions, camera angles, CTAs, pacing
- Reverse-engineer the psychology: Why would this stop a scroll?
- Adapt trends to the client's niche (don't invent, adapt)

**Phase 2: Production (Execution)**
- Follow shot list
- Capture multiple angles and takes
- Get clear, usable audio (if video)
- Get variety in framing and composition

**Phase 3: Post-Production (Refinement)**
- Edit with purpose (every cut should serve the hook or message)
- Add captions/text that reinforces the message
- Optimize pacing for platform (TikTok: fast; Facebook: conversational)
- Include clear CTA (follow, comment, message, shop, book, etc.)
