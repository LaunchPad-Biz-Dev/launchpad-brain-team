# Content Strategy Framework

**Rewritten 2026-10-07.** The system itself (pillars, buckets, jobs, series, the ten-section client strategy, brief tagging) now lives in [[Content Framework Method]]. This note is the companion: how to audit a client before building, how to run the calendar, how to measure, and what goes wrong. The previous version of this note used "pillars" for what are now buckets (Education / Relatability / Conversion); that section is retired. Archived copy: `_archive/Content Strategy Framework — pre-2026-10-07.md`.

**Core Philosophy:** Consistency beats perfection. A system beats randomness.

**Three pillars of success (Launchpad-level, not client pillars):** Better Content → Better Leads → Better Systems. Every client strategy serves this progression; see [[Core Framework]].

---

## Content Audit & Baseline (before building a strategy)

### Questions to ask
- What content has worked in the past? (high engagement, conversions, shares)
- What platforms do we own? (Instagram, TikTok, YouTube, email list, etc.)
- What's the current posting frequency?
- What tools/systems exist? (design, video, CRM, scheduling)
- What's the bandwidth? (team capacity, outsourcing budget)
- What are the constraints? (brand guidelines, compliance, approval workflows)
- Who approves content, and how fast?

### Audit output
- **Content inventory:** everything existing (format, platform, performance)
- **Baseline metrics:** current reach, engagement, conversion
- **Gaps by bucket:** which of Awareness / Desire / Story / Choice is starved (most clients: all Awareness, no Choice; or all Choice, no Story)
- **Candidate pillars:** the products, services, audiences and themes the client keeps coming back to
- **Competitive landscape:** what competitors do, good and bad

The audit feeds steps 1–3 of the build process in [[Content Framework Method]] (discovery → insight → pillars).

## Content Creation Workflow

### Phase 1: Ideation & Planning
1. Brain dump ideas into the strategy's idea bank
2. Tag each one (Pillar · Bucket · Job · Series) — if it can't be tagged, it isn't ready
3. Map to calendar against the pillar mix
4. Assign owner
5. Estimate effort (quick post vs production day)

### Phase 2: Strategy & Brief
1. Clarify the objective of the piece (its job)
2. Confirm the audience (from the strategy's audience section)
3. Write the brief ([[Brief Creation]]) with the tag at the top
4. Lock messaging; pull in a recurring message if one fits
5. Approvals (client, legal, brand) against the strategy's guardrails checklist

### Phase 3: Creation
1. Plan the shoot, grouped by pillar ([[Shot List Creation]])
2. Capture
3. Design / edit ([[Content Workflow — Shoot to Post]]); series name sets the cut, job sets the tone
4. Copy and captions (no dashes in captions)
5. Quality check against the bucket's qualities

### Phase 4: Distribution
1. Schedule per [[SMM Posting Calendar Patterns]] and [[Contracted Monthly Deliverables]]
2. 8 AM–8 PM client local, varied times
3. Hook in the first line
4. Engage immediately

### Phase 5: Analysis
1. Track metrics by bucket
2. Note winners and why
3. Identify patterns (series, formats, jobs)
4. Update the strategy: pillar mix, series, theme

## Themes (time-bound layers)

A theme is a monthly or quarterly angle layered over the pillars. It has an end date. Themes give the calendar momentum without changing the pillars.

Examples: a seasonal push (Spring Break safety for a PI firm), a launch month (First Colony November), a cultural moment (Día de los Muertos for A Mi Manera), a recurring monthly series ("What's new in mortgages this month"). Each month, 2–3 pieces carry the theme; the rest is normal pillar work.

If an angle keeps coming back every quarter, promote it to a pillar.

## Measurement & Iteration

### Metrics by bucket

| Bucket | What to watch |
|---|---|
| Awareness | Reach, impressions, saves/shares, new followers |
| Desire | Watch time, saves, comments, profile visits, link taps |
| Story | Shares, comments, DMs, mentions |
| Choice | Click-through, form submissions, calls, bookings, cost per lead |

Roll-up to the Launchpad pillars: Better Content (Awareness + Desire), Better Leads (Choice), Better Systems (email open rates, return visits, lifetime value).

### Monthly review (Week 1 of the cycle)
1. Pull metrics for all posts, grouped by pillar and bucket
2. Top performers: which series, which jobs, which formats
3. Underperformers: same question
4. Decide: move the pillar mix, retire or add a series, adjust a theme
5. Write it into next month's Content Strategy Brief

### Questions to ask
- Which formats drive engagement? (video > carousel > single image?)
- Which jobs resonate? (educate vs entertain vs prove)
- Which series are compounding?
- Which platforms convert?
- Is any bucket starved?

## Common Content Strategy Mistakes

1. **Inconsistency:** sporadic posting doesn't build audience
2. **Untagged content:** if it has no pillar, bucket and job, it has no reason to exist
3. **Wrong metrics:** followers over conversions
4. **Unclear audience:** creating for "everyone"
5. **Too many platforms:** spread thin instead of owning one or two
6. **Copying competitors:** instead of the client's own insight
7. **Perfectionism:** waiting for perfect instead of posting good and iterating
8. **No Choice content:** awareness with no next step
9. **Renaming the buckets per client:** the bucket stays; the job changes
10. **Pillars that change monthly:** those were themes
