# Launchpad Brain — Team Copy

This is a **read-only, auto-synced copy** of the Launchpad Brain: client context, brand
guidelines, packages, processes, and intelligence. Use it as the knowledge base for the
Claude app so every answer is grounded in what is actually true about us and our clients.

**How to use it in Claude** → see `Onboarding/Claude Team Setup Guide.md`.

**Obsidian:** clone this repo with GitHub Desktop and open the cloned folder itself as a
vault (Obsidian → Open folder as vault). The `.obsidian` config ships with it, so the graph, backlinks, folder colors and
`index.md` work out of the box. Pull in GitHub Desktop to refresh.

**Do not edit files here.** Edits here are overwritten on the next sync. To add knowledge
to the Brain, say **"chat clip that"** to Apollo in Slack (or DM Apollo what you learned),
and it lands in the real Brain, then shows up here.

Private and internal. Never share outside Launchpad.
