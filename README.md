# Launchpad Brain — Team Copy

This is an **auto-synced copy** of the Launchpad Brain: client context, brand guidelines, packages,
processes, and intelligence. Use it as the knowledge base for the Claude app so every answer is
grounded in what is actually true about us and our clients.

**How to use it in Claude** → `Onboarding/Claude Team Setup Guide.md`.

**Obsidian:** clone this repo with GitHub Desktop and open the cloned folder itself as a vault
(Obsidian → Open folder as vault). The `.obsidian` config ships with it, so the graph, backlinks,
folder colors and `index.md` work out of the box. Pull in GitHub Desktop to refresh.

**How the Brain learns from you:** your Claude account runs a scheduled **daily dump** at end of day
(set up once, see the guide). It lands in Drive, and every night the Mac Mini files it into the real
Brain. By morning it is here for everyone. Nothing for you to do after setup.
If you work in Cowork with this folder, you may also drop notes into `_inbox/{your name}/` and push
them with GitHub Desktop; they are harvested the same night. Edits anywhere else are overwritten on
the next sync (a copy is kept for review).

Private and internal. Never share outside Launchpad.
